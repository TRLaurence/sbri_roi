# nihr_roi
A repo for modelling the Return on Investments of several different NIHR funded projects.

You need to ensure your directory structure matches R/utils_paths.R

You need parameters, ons population and funding data to make the model run contact timothy.laurence@permaanalytics.com for information. These should be placed in the the directory indicated by your raw_path file path.

You can restore all required packages using renv::restore() https://rstudio.github.io/renv/reference/restore.html
